# 技术英语生词本

给嵌入式软件工程师用的英文生词收集＋间隔重复复习工具。看到不认识的词或短语，扔进来，
它会给出**结合嵌入式语境**的解释（大模型 / 在线词典 / 离线词库三种来源可切换），
能发音，按 Anki 那套间隔重复算法安排复习，电脑和手机共用同一份词库。

## 功能

- **收录**：单词、短语、整句都能收；自动记录时间戳、来源文档、你遇到的**原句**（原句会让释义贴合你的真实语境）。
- **拼写检查**：单个单词查词时顺带判断拼写；疑似拼错会给出建议和「改用 / 保留原文」两个选项。
  选择「改用」会直接改掉词条拼写并重新查释义，**复习进度不会丢**；如果正确拼写已经在词库里，会自动合并。
  短语、缩写、型号不会被误判；老词条（升级前收录的）打开详情时也会补查一次。
- **词库管理**：列表每行右侧有删除按钮；详情里可以改拼写、改笔记和标签。
- **释义（三种来源，随时切换）**
  - 大模型：默认，解释最贴合技术语境，含技术语境说明、常见搭配、易混辨析、可直接抄用的写作例句、记忆钩子、缩写全称。
  - 在线词典：有道智云 / 百度翻译 / dictionaryapi.dev（免费无需 Key）。
  - 离线词库：ECDICT（340 万词条），无网络也能查。
- **发音**：默认用有道公开发音接口（免费、国内可直连），服务端缓存音频文件；失败时自动退到浏览器内置语音。支持英音/美音。
- **复习**：Anki 同源的调度方式（学习步长 + SM-2 式的间隔增长），四档评分并显示每档的下次间隔；支持键盘 1/2/3/4 评分、空格看答案。
- **统计**：待复习数量、连续打卡、近 30 天复习量、标签分布，以及「查了 3 次以上还没记住」的重点词提醒。
- **多设备**：服务端自建，浏览器（PWA 可加到手机主屏）访问同一份数据；离线时复习结果先存本地，联网后自动补传。

## 快速开始（Windows）

```bat
:: 双击 start.cmd 也可以，它会自动装依赖、构建、启动
start.cmd
```

启动后浏览器打开 <http://localhost:8787>。**首次启动会在控制台打印一个随机登录密码**，请记下它，
登录后在「设置」里可以修改，也可以用命令重置：

```bat
npm run set-password -- 你的新密码
```

手动分步：

```bat
npm run setup     :: 安装前端依赖
npm run build     :: 构建前端
npm start         :: 启动服务（同时提供网页和 API）
```

改前端代码时用开发模式（两个窗口）：

```bat
dev.cmd
:: 或者分开跑
npm run dev:server
npm run dev:web
```

需要 Node.js 22.5 以上（用到内置的 `node:sqlite`，所以服务端**零第三方依赖**，不需要编译原生模块）。

## 首次使用要做的两件事

### 1. 配置大模型（推荐）

登录后进「设置 → 大模型」，填 Base URL、模型名和 API Key。任何 OpenAI 兼容接口都能用：

| 服务 | Base URL | 模型名 | 说明 |
| --- | --- | --- | --- |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` | 便宜、中文好、国内直连，默认选项 |
| 阿里通义 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` | 有免费额度 |
| 智谱 GLM | `https://open.bigmodel.cn/api/paas/v4` | `glm-4-flash` | 有免费额度 |
| 硅基流动 / OpenRouter 等 | 各自文档 | 各自模型 | 通用 OpenAI 兼容层 |

没有 Key 也能用：启用「在线词典」里的 `dictionaryapi.dev`（免费不用 Key，但只有英文释义），
或者装离线词库。想先验证链路，可以跑 `npm run mock:llm` 起一个假模型，
把 Base URL 填成 `http://localhost:8899/v1`、Key 随便填——它返回的是固定占位内容，不能用来学习。

### 2.（可选）装离线词库

1. 到 [skywind3000/ECDICT](https://github.com/skywind3000/ECDICT) 的 Releases 下载 `stardict.7z`（里面有 `stardict.db`）
   或 `ecdict-csv.7z`。
2. **用 stardict.db**：解压后改名成 `ecdict.db`，放进 `server/data/` 目录即可。
3. **用 CSV**：转换一次即可

   ```bat
   node server/src/tools/import-ecdict.js D:\downloads\ecdict.csv
   ```

装好后在「设置 → 离线词库」点「测试离线查询」验证。个人使用免费，商用前请自行确认授权。

## 多设备同步怎么用

方案是**自建服务端 + 手机当网页 App 用**，不需要写手机原生 App：

1. 在常开的电脑（或服务器）上跑 `npm start`。
2. 手机浏览器打开 `http://<电脑的局域网IP>:8787`。
3. iOS Safari / Android Chrome 菜单里选「添加到主屏幕」，就变成一个全屏 App 图标了。
4. 如果网页和 API 不在同一个地址（比如网页部署在别处），在「设置 → 账号与地址 → 服务器地址」里填 API 地址。

要在外面（不连家里 WiFi）也能用，见 [docs/部署方案.md](docs/部署方案.md) 里的服务器建议。

## 数据与备份

- 全部数据在 `server/data/`：`english-learn.db`（词条、释义、复习进度）、`config.json`（配置与密码）、`audio/`（发音缓存）。
- 换机器把整个 `server/data/` 拷过去就行。
- 「设置 → 数据」里可以导出全部词条为 JSON。
- `server/data/` 已在 `.gitignore` 里，不会被提交。

```

  src/api.js                所有 API 与鉴权
  src/db.js                 SQLite 表结构与数据访问

  src/providers/            三种释义来源 + 发音
```

## 已知边界

- 单用户：只有一个登录密码，没有多账号体系（本来就是给自己用的）。
- 大模型释义按词条缓存，换来源会在词条里保留多份释义；同一词条重复查询会累加「查询次数」，用来做「查了很多次还没记住」的提示。
- 离线只支持**复习**排队补传和已缓存词条的查看；离线**新增生词**需要联网（会提示失败）。
- 服务端默认监听 `0.0.0.0:8787`，暴露到公网前请务必设置强密码，或参考部署文档用 Tailscale / Cloudflare Tunnel 避免直接开放端口。
- 发音走的是有道公开接口，属非官方用法；如果哪天失效了，把「设置 → 发音来源」切成关闭，就用浏览器内置语音。
