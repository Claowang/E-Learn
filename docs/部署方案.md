# 部署与服务器选型

目标：让手机在外面（4G/5G）也能打开这个工具，和电脑共用同一份词库。

结论先给：**优先不租服务器**。除非你需要一个固定的公网地址，否则零成本方案已经够用，
而且更安全。

---

## 一、先想清楚：你要的是哪种「自建」

| 形态 | 成本 | 出门能用吗 | 说明 |
| --- | --- | --- | --- |
| A. 家里/实验室机器 + Tailscale | 0 元 | 能 | **推荐**，组虚拟局域网，不用公网 IP、不用备案、不暴露端口 |
| B. 家里机器 + Cloudflare Tunnel | 0 元（要域名约 ¥50/年） | 能 | 想要一个 `https://xx.你的域名` 时用 |
| C. 租一台最便宜的云服务器 | ¥60～200/年 | 能 | 需要 7×24 稳定、独立 IP、不想依赖家里机器 |

三种都只需要跑一个 `node server/src/index.js`，SQLite 单文件数据库，1 核 512M 的机器绰绰有余。

---

## 二、方案 A：不租服务器，用 Tailscale（首选）

Tailscale 是免费的内网穿透/组网工具（个人版免费，够用），装完之后你的电脑和手机就像在同一个
局域网里，直接访问 `http://电脑的TailscaleIP:8787` 就行。不用公网 IP、不用端口转发、
不经过第三方服务器转发数据，也不涉及备案。

1. 电脑和手机都装上 Tailscale 并用**同一个账号**登录（<https://tailscale.com/download>）。
2. 电脑上启动服务：`npm start`（默认监听 `0.0.0.0:8787`）。
3. 在 Tailscale 后台或 `tailscale ip -4` 查到电脑的 100.x.x.x 地址。
4. 手机浏览器打开 `http://100.x.x.x:8787`，登录一次，然后「添加到主屏幕」。

手机端 Tailscale 建议开「Always-on VPN」，这样每次打开 App 都能直接连上。

**这个方案什么时候不够用**：电脑关机就用不了；需要把地址分享给别人用；公司网络禁止装 VPN 类工具。

## 三、方案 B：Cloudflare Tunnel（想要自己的域名）

适合家里有常开机器、想要一个 https 地址的人。需要先有一个域名（Cloudflare Registrar、
Namecheap、腾讯云/阿里云买都行，`.top`/`.xyz` 首年几元到几十元）。

1. 域名接入 Cloudflare（免费套餐即可，DNS 托管过去）。
2. 电脑上装 `cloudflared`，执行 `cloudflared tunnel login` → `cloudflared tunnel create english-learn`。
3. 把隧道指向本地服务：`cloudflared tunnel route dns english-learn vocab.你的域名`，
   并在配置文件里把 `service` 设为 `http://localhost:8787`。
4. `cloudflared tunnel run english-learn`，手机打开 `https://vocab.你的域名`。

好处：不用开放任何端口、自带 HTTPS、免费。域名放在 Cloudflare 托管，不涉及国内备案。

## 四、方案 C：租一台便宜的云服务器

### 4.1 国内云（延迟最低，但要实名；用 IP+端口访问不需要备案）

| 选项 | 大致价位 | 说明 |
| --- | --- | --- |
| 腾讯云 轻量应用服务器 | 新用户/活动价常在 ¥50～150/年（2核2G 级别） | 国内访问快，活动价性价比最高，建议蹲活动 |
| 阿里云 轻量应用服务器 | 与腾讯云接近 | 同上，两家轮着看活动 |
| 腾讯云/阿里云 学生机 | ¥10/月起（需学生认证） | 如果还是学生，这个最划算 |
| 雨云 / 硅云 / 青云等小厂 | 更低 | 便宜但稳定性与服务参差，注意选择支持备选线路的 |

**备案要注意的点**：

- 只用 `http://IP:8787` 访问 → **不需要备案**，这也是推荐做法（本工具自带登录密码）。
- 想用域名 + 80/443 端口访问国内服务器 → 需要域名备案（耗时 1～4 周），个人自用没必要折腾。

### 4.2 国外云（无需备案实名，国内访问延迟略高）

| 选项 | 大致价位 | 说明 |
| --- | --- | --- |
| RackNerd | $10～25/年（1核1G） | 常年有年付特价，性价比高，工单支持一般 |
| CloudCone / GreenCloud | $15～30/年 | 同类低价商家 |
| 搬瓦工（BandwagonHost） | $49/年起 | 线路更稳，价格高一档 |
| Oracle Cloud 永久免费 | 0 元（Always Free ARM 4核24G） | 真免费，但注册常被风控拒绝，需国际信用卡 |
| Fly.io / Railway / Render | 免费额度内 0 元 | 能跑，但免费实例会休眠，需要额外配置持久化卷（SQLite 要放 volume） |
| Vultr / DigitalOcean | $5～6/月 | 贵，胜在稳定、按小时计费 |

如果只是自己用，我不建议为这个工具买 $5/月的机器——它平时几乎不占资源。

## 五、在服务器上部署（以 Ubuntu + 国内轻量服务器为例）

```bash
# 1. 安装 Node.js 22（用 NodeSource 源）
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt-get install -y nodejs
node -v   # 需要 >= 22.5

# 2. 上传代码（git clone 或 scp 整个目录到 ~/english-learn）
cd ~/english-learn

# 3. 装依赖并构建前端
npm run setup
npm run build

# 4. 设置一个强密码（会写进 server/data/config.json）
npm run set-password -- '你的强密码'

# 5. 先手动跑一遍确认没问题
npm start
```

浏览器打开 `http://服务器IP:8787`，确认能登录后按 Ctrl+C 停掉，改成常驻服务：

```bash
sudo tee /etc/systemd/system/english-learn.service > /dev/null <<'EOF'
[Unit]
Description=english-learn vocab tool
After=network.target

[Service]
Type=simple
User=ubuntu
WorkingDirectory=/home/ubuntu/english-learn
ExecStart=/usr/bin/node server/src/index.js
Restart=always
RestartSec=3
Environment=NODE_ENV=production

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl daemon-reload
sudo systemctl enable --now english-learn
sudo systemctl status english-learn
```

放行端口（Ubuntu 自带的 ufw；云厂商控制台的**安全组**里也要放行同一端口）：

```bash
sudo ufw allow 8787/tcp
```

更新代码后：

```bash
cd ~/english-learn && git pull
npm run setup && npm run build
sudo systemctl restart english-learn
```

## 六、安全与备份

- **一定要改默认密码**：首次启动会打印随机密码，如果能联网访问，第一件事就是 `npm run set-password`。
- 想更省心就用方案 A/B，不把端口直接暴露在公网。
- 如果必须公网直连，建议顺手把端口从 8787 换成不常见的高位端口，并限制云服务器安全组只放行该端口。
- 备份只要拷 `server/data/` 目录（`english-learn.db` + `config.json` + `audio/`）。
  小技巧：在电脑上设个定时任务，每天 `scp` 一次这个目录即可；网页端「设置 → 数据」也能随时导出 JSON。

## 七、手机端建议

- iOS：Safari 打开 → 分享 → 「添加到主屏幕」。加到主屏后是全屏无浏览器边框的，和原生 App 观感一致。
- Android：Chrome 打开 → 右上角菜单 → 「安装应用」/「添加到主屏幕」。
- 常用复习的话，把图标放在首屏，每天通勤时点开刷几分钟——复习队列、评分和离线补传都是为手机场景设计的。
